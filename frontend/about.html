MACHINE LEARNING PROJECT

Student Marks Predictor

A machine learning based web application designed to estimate student final marks from academic performance data.

MODEL Linear Regression
BACKEND FastAPI
DATABASE MySQL
FRONTEND HTML • CSS • JavaScript

Prediction Inputs

The system uses four academic inputs: study hours, attendance, previous marks, and assignment score.

Project Workflow

Student information is submitted through the frontend, processed by the FastAPI backend, passed to the trained machine learning model, and the predicted final marks are returned to the user.
